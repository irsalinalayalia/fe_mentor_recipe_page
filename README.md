### What I learned

While building this recipe page, I learned:

How to structure semantic HTML using tags like <main>, <article>, and <section> for better accessibility and readability.

- How to use custom fonts with @font-face and apply them effectively across different text elements.
- The use of CSS variables (:root) to manage colors, typography, and spacing consistently.
- Building a responsive layout using Flexbox, clamp(), and media queries.
- Styling lists and tables for a clean, readable presentation.
- Maintaining clean, modular code by separating structure (HTML) from styling (CSS).

This project helped me get more comfortable with layout styling, reusable design tokens (variables), and interactive hover states for better visual feedback.
